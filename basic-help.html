Basic Office Software Tools

You may be starting up and unsure of what can be done on your PC, or recognise a need to move from a manual paper and pen system to using your pc.
If you are buying a Pc for businss, best go with Microsoft windows Pc's. Also get the Microsoft Office package.
Once you have these, you have the frame of a decent office system.

Word: Documents, Files, Email and Letters

Letters are always better done on a Pc, especially as email replaces posted. You can set up an email address (Google gmail is always good) and use the hotmail directly to write your letters, though Word is the best tool here. You can set up a windows filing system, and check your letters on the pc.
You can produce invoices using word (though Excel spreadsheets are more suited)

A simple lesson with some templates will get you going.

Excel: Spreadsheets. Formatted calculations, Planning, Invoicing etc

Cash calculation and invoicing is likely a part of your everyday. This can be done simply in Microsoft Excel.
A basic lesson with some templates will get you going.

Teams: Online communication.

You may want to communicate online, and be able to view each other's Pc screen. This can be done simply with Microsoft Teams. Most businesses and institutions use Teams. I use Teams. It was invaluable during Covid Lockdown. If you have kids, you'll know.

Powerpoint and Access.

Brochures or catalogues? Use powerpoint.
Too many Spreadsheets?
They can be linked and data read over sheets, but in all likelihood, an Access database is the tool for this job.
